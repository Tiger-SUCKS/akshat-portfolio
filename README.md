# Akshat Vishal Sinha — Developer Portfolio

A modern dark developer/tech portfolio built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Personalize

1. Put your professional image at `public/profile.jpg`.
2. Replace the LinkedIn and GitHub `href="#"` values in `src/App.jsx`.
3. Update project descriptions/links when the real live URLs are available.
4. Update any current job/company wording if you want the exact employer name displayed.
